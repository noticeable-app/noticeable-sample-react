# Noticeable React Sample

This project shows how to integrate Noticeable Widgets in a React Web app.

The repository's commit history walks through the integration step by step:
https://github.com/noticeable-app/noticeable-sample-react/commits/main

## Stack

- React 19
- React Router 7
- Vite 7
- TypeScript

## Run locally

```sh
npm install
npm run dev
```

Then open `http://localhost:3000/`.
